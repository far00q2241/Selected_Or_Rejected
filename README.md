# 🎓 Candidate Selection Prediction

A Machine Learning classification project that predicts whether a candidate is **Selected** or **Rejected** based on candidate information, education, experience, skills, certifications, assessment scores, and job preferences.

## 🤖 Models Used

* Logistic Regression
* Random Forest
* XGBoost
* Gradient Boosting

**Best Model: XGBoost**

* F1 Score: **0.8473**
* Recall: **0.8710**
* Balanced Accuracy: **0.8412**

## 🛠️ Technologies

* Pandas
